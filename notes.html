History of Computing - Quick Reference

The Seven Computing Eras

Era Years Core Technology Landmark Machines
Mechanical 1642-1820 Gears and cranks Pascaline, Arithmometer
Modern/Design 1822-1884 Mechanical, programmable in concept Analytical Engine
Pre-Electronic 1884-1945 Punched cards, relays, vacuum tube invented Tabulating Machine, Mark I
1st Generation 1946-1958 Vacuum tubes ENIAC, EDVAC, UNIVAC
2nd Generation 1956-1963 Transistors PDP-1, IBM 7094
3rd Generation 1964-1971 Integrated Circuits IBM System/360
4th Generation 1971-present Microprocessors Altair 8800, Apple II, IBM PC

Note: Generations 1 and 2 overlap from 1956 to 1958.

Mechanical Era (1642-1820)

Blaise Pascal (France) - 1642

  • Invented the Pascaline
  • Could perform addition and subtraction only (2 operations)

Gottfried Wilhelm von Leibniz (Germany) - 1673

  • Invented the Step Reckoner
  • Strong advocate of the binary system
  • Multiplication by repeated addition and shifting

Joseph Marie Jacquard (France) - 1801

  • Invented the Jacquard Loom
  • Used punched wooden cards to automate weaving patterns
  • Babbage and Hollerith later borrowed the punched card concept

Thomas de Colmar (France) - 1820

  • Invented the Arithmometer
  • First commercially successful mechanical calculator
  • Could perform all 4 operations
  • Manufactured from 1851 to 1915

Key distinction: Pascal's device = 2 operations, de Colmar's = 4 operations

Modern/Design Era (1822-1884)

Charles Babbage (England)

  • Difference Engine (1822) - computed polynomial functions
  • Analytical Engine (1837) - first general-purpose computer design
  • Never completed due to funding and manufacturing limitations

Ada Lovelace

  • Recognized as the first computer programmer
  • Wrote notes on the Analytical Engine
  • Described the first algorithm intended for machine processing

Pre-Electronic Era (1884-1945)

Herman Hollerith

  • Created the Tabulating Machine for 1890 US Census
  • Used punched cards (borrowed from Jacquard)
  • Founded company that became IBM

Key Machines

  • ABC Computer (Atanasoff-Berry) - first electronic digital computer
  • Harvard Mark I (1944) - electromechanical, Harvard architecture
  • ENIAC (1946) - first general-purpose electronic computer

First Generation (1946-1958)

Key Machines

  • ENIAC - Electronic Numerical Integrator and Computer
  • EDVAC - first stored-program computer design
  • UNIVAC - first commercial computer in the US
  • IAS Machine - von Neumann architecture

Architecture Comparison

Harvard Architecture von Neumann Architecture
Separate memory for instructions and data Single memory for both instructions and data
Can fetch both simultaneously Sequential access (von Neumann bottleneck)
Example: Harvard Mark I Example: IAS Machine, most modern CPUs

Second & Third Generation

2nd Generation (1956-1963) - Transistors

  • DEC PDP-1 - first minicomputer
  • IBM 7094 - scientific computing
  • Transistors replaced vacuum tubes - smaller, more reliable

3rd Generation (1964-1971) - Integrated Circuits

  • IBM System/360 - family of compatible computers
  • ICs combined multiple transistors on a single chip

Fourth Generation (1971-Present)

Key Milestones

  • Intel 4004 (1971) - first commercial microprocessor
  • Altair 8800 (1975) - sparked personal computer revolution
  • Apple II (1977) - first successful mass-produced PC
  • IBM PC (1981) - established PC standard

Internet & Web

  • ARPANET (1969) - precursor to the Internet
  • TCP/IP (1983) - standard Internet protocol
  • World Wide Web (1991) - Tim Berners-Lee at CERN

Intel x86 Registers

General Purpose Registers

Register Name Common Use

BX Base Base pointer for memory access
CX Counter Loop counting
DX Data I/O operations, multiplication/division

Key "Firsts" in Computing

  • First mechanical calculator: Pascaline (1642)
  • First commercially successful calculator: Arithmometer (1820)
  • First programmer: Ada Lovelace
  • First electronic digital computer: ABC Computer
  • First general-purpose electronic computer: ENIAC
  • First stored-program computer: EDVAC (design), Manchester Baby (operational)
  • First commercial computer (US): UNIVAC
  • First minicomputer: PDP-1
  • First microprocessor: Intel 4004
  • First personal computer kit: Altair 8800
